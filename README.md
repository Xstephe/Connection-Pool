# 项目：MySQL 连接池

实现了一个高效的 MySQL 连接池，优化数据库连接的管理和性能。该连接池使用 C++11 特性，充分利用了多线程编程和智能指针，以支持高并发环境下的数据库操作。

## 关键技术

- **多线程编程**：利用 `std::queue` 和 `mutex` 实现线程安全的连接管理。
- **智能指针**：使用 `shared_ptr` 和 `lambda` 表达式，简化资源管理与内存泄漏风险。
- **TCP/IP 协议**：确保与 MySQL Server 的高效通信。

## 连接池功能介绍

- **最大连接数 (maxSize)**：用户可设置最大连接数，以适应不同的应用需求。
- **连接超时 (connectionTimeout)**：实现了连接超时机制，确保长时间未使用的连接会被自动回收。
- **动态调整**：根据实际负载情况动态调整连接池中的连接数量，以优化性能。

## 开发平台

- **开发环境**：Windows 和 Linux 平台下进行开发与测试，确保跨平台兼容性。
- **性能测试**：通过压测工具验证连接池的性能，结果表明在高并发情况下，连接池能够有效降低响应时间。

## 性能测试结果

在不同的并发情况下，连接池的响应时间表现良好：

- 5000 请求：平均响应时间 403ms
- 10000 请求：平均响应时间 2041ms
- 100000 请求：平均响应时间 4589ms
